# About this book

This is a living document: the repository that hosts these words also
hosts the tool that renders them, and every paragraph carries its own
history. Click (or tap) any paragraph to see who wrote it and who
vouches for it.

Changes flow through review. Anyone with access can propose an edit —
from the command line with `book submit`, or directly from this page
with the ✏️ button in the paragraph popup. Each proposal becomes a pull
request; a rendered diff page shows exactly what would change, down to
individual symbols inside formulas; and when the maintainer merges it,
this site rebuilds itself.

Trust is recorded, not implied. A vouch is a signed statement, committed
to the repository, that a specific version of a specific paragraph has
been checked. If the paragraph changes later, the vouch goes stale
automatically — it is keyed to the content itself, not to a page or a
position.

Try it: sign in (bottom-right corner), then vouch for this paragraph,
start a discussion about it, or propose a better wording. Your action
becomes a discussion, a commit, or a change under review on this
course's own forge — nothing is stored anywhere else.
