How it works

The site is static files; the self-hosted forge behind it is the backend. Your ORCID iD is your account — sign in with ORCID and you can contribute; there is nothing else to register. The browser talks directly to the forge API — your sign-in is stored only in this browser — git is the database, and CI re-renders what you see. Discussions, accounts and changes all live on the course's own infrastructure; nothing is stored on a third-party service. The CLI (pipx install book-cli) offers the same workflow from a terminal — see the guides in the repository.
